## What the list is saying

This is another **agent-skills day**, not a diversified engineering chart.

1. **Skills and harnesses dominate.** Matt Pocock, Anthropic, HumanLayer, WorldFlowAI, ECC, ponytail, ruflo, and OpenCode are all competing for the same slot: “make my coding agent behave.” Installing several at once will fight over instructions and burn context.
2. **Two real libraries leaked through.** `{fmt}` and `nvm` are the only entries you would still use if coding agents disappeared tomorrow.
3. **Local compute is the secondary theme.** Magnitude exists so the same agents can talk to models on your machine instead of an API bill.
4. **Catalogue repos are back.** FckSignups is a directory. exploitarium is a research archive. Neither is software you “deploy to try.”
5. **Momentum ≠ quality.** Stars-today ranks velocity. A 3k-star focused pack (humanlayer/skills) can be more useful than a 250k-star kitchen sink.
